If so, here’s a simple example of a basic LaTeX document:

\documentclass{article}
\usepackage[utf8]{inputenc}

\title{My First LaTeX Document}
\author{Your Name}
\date{\today}

\begin{document}

\maketitle

\section{Introduction}
This is my first document written in \LaTeX. It’s a powerful typesetting system for creating beautiful documents, especially for mathematics and scientific writing.

\section{Mathematics Example}
Here’s an inline equation: \( E = mc^2 \).

And here’s a displayed equation:
\[
\int_0^{\pi} \sin(x) \, dx = 2
\]

\section{Conclusion}
LaTeX makes it easy to produce professional-looking documents.

\end{document}
